### 科学评审到返修、复审

测试稿故意写入“鼠模型观察已确立人体生存获益”，而唯一来源明确没有人体试验或
人体生存结果。任务图包含 review → revise → re-review，常规表述修复已授权。

实际结果：

1. 初审定位 R1，记录来源、位置和 major 结论，保留原稿 v1。
2. 写作任务把无依据人体获益改为条件性临床前假说，仅修改相关位置，保存 v2。
3. 建立 revision_ledger，关联 R1、修改、来源和状态。
4. 复审实际 v2，将 R1 关闭，四个已有任务均完成；没有自动投稿或进入推广。

轨迹包含 workflow.mjs、omp-write.md 与 omp-review.md。检查了任务状态、两版稿件、
问题记录和复审日志，并断言错误句保留于 v1、从当前稿消失、当前稿与 v2 快照一致。
