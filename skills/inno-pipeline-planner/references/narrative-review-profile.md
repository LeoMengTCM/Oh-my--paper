# 叙述性综述共享规则

适用于 `pipeline.track = narrative-review`，该正式声明优先于旧兼容字段。旧项目的 `projectContext.researchType`、`projectContext.articleType` 或根级同名字段标为 `narrative-review` 时，也按本规则解释阶段，不因旧 track 为 ml 或 clinical 而强加训练或临床试验要求。新项目使用正式 track，不继续借用其他类型。仅靠旧字段解释且方法声明互相矛盾时先核实，不自动迁移或覆盖。

## 初始化与研究边界

- 默认 `analysisMode = exploratory`，表示可以依据检索结果调整综述范围；不表示可以为了支持预设结论选择性报告证据。
- 保留研究者明确给出的主题、文章类型、写作语言和起始阶段，不重复询问已知信息。不推定作者、目标期刊、最终题目或研究方案已批准。写作语言读取 `projectContext.writingLanguage`，兼容旧根级 `writingLanguage`；新项目只写前者，避免两个值发生冲突。
- 缺少 `.pipeline/docs/research_brief.json` 或 `.pipeline/tasks/tasks.json` 时先执行 setup。只有结构建立且配置、任务契约有效，才能报告初始化完成。
- 不自动创建临床专用 `protocol.md` / `sap.md`，不默认要求 RCT 注册、IRB、双人独立筛选、PRISMA、RoB 2 或 GRADE。发生真实方法变化、涉及患者个体资料或期刊另有要求时，重新核实并记录适用条件。
- 叙述性综述与“系统综述中的叙述性综合”不同。没有完整系统综述方法，不得把前者写成后者；本 track 不自动执行或宣称 Meta 分析。

## 五阶段含义

| 阶段 | 工作 | 可核对的产物 |
|---|---|---|
| survey | 查指南、已有综述与原始研究，记录真实检索过程和材料可得性 | 检索日志、候选文献、与已有综述的范围比较、未解决问题 |
| ideation | 在已有证据上确定文章重点、读者与论证结构 | 研究者确认的综述范围和主问题、初步提纲；不强制五个创新点或创新性评分 |
| experiment | 提取、核对、比较和综合真实原文证据 | 带出处的证据表、不同研究的异同和局限、关键论断与依据的对应关系 |
| publication | 按主题写作，核验引文和关键数字，科学评审、返修与复审 | 稿件、参考文献库、当前版本的审查和处理记录 |
| promotion | 仅在用户请求时制作汇报或传播材料 | 与已核对稿件一致的交付物；不自动投稿或对外上传 |

## 检索和全文

1. 记录实际执行的数据库、检索式、日期、过滤条件、取回数量和截断/失败情况。精选文献表不是完整数据库筛选，不能产生正式 PRISMA 纳入计数。
2. 用指南和已有综述定位临床争议，再查关键原始研究。引用量、期刊等级和全文可得性不是科学可信度的替代指标。
3. 清楚区分书目信息、摘要、已获取全文、已读取全文。未获得全文的研究保留缺口，不把摘要扩写成全文结论。
4. 只合法获取材料；外部 OCR 或其他服务接收文件之前按其适用授权要求处理。已有可用全文文本时，不把收费 OCR 设为无条件前置要求。
5. 中文、英文等材料的纳入按研究问题决定；稿件语言不等于文献语言限制。内部记录遵循用户偏好，不强制每个文件另写双语副本。

## 证据提取与写作

- 重要数字保留研究人群、研究设计、分母、随访时间、结局定义和原文定位；核对相对风险与绝对风险、发生率与患病率等是否被混淆。
- 区分原始研究发现、指南建议、既有综述解释和本文判断。报告互相冲突的结果及可能原因，避免只保留支持主张的研究。
- 参考文献必须能核对真实来源；书目存在不等于支持所引用的论断。引用语境核对与元数据检查分别记录。
- 默认按主题组织正文，交代文献选择方法及局限性；不为套用 IMRaD 虚构 Methods、Results 或原始数据。目标期刊的明确格式要求优先。
- 只规划确实有助于解释的表格、概念图或临床流程图，不强制每阶段一图，不虚构筛选计数、森林图或效应量。数据图必须来自已核实数据。
- 综述范围或稿件发生实质变化后复核受影响的检索、证据表与审查记录，不能用旧版审查放行新版。

## 完成与交接

- 任务完成应有实际产物和具体完成说明；阶段名、done 标记或空文件不能代替证据。
- 未核实来源、缺全文、未解决临床争议分别标记；不将“可起草”写成“可投稿”。
- 方法透明度、证据覆盖、论断支持、临床适用性与局限性是叙述综述的评审重点，不用临床试验或 ML 会议评分模板替代。
- 程序校验只保证它实际检查的内容；模型的提示词规则和软件回归测试不构成研究者批准或真实文献质量验收。
