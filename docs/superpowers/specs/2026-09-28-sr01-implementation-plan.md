# SR-01 实施计划

日期：2026-09-28
依据：已批准的 `2026-09-28-rct-systematic-review-design.md`。

## 范围

只实现规则与入口修复，不实现完整检索器、筛选数据库或 Meta 分析适配器。现有 CLI/命令名保持不变；新增共享 profile 和任务规范化模块。

## 顺序与验收

1. 针对两个插件的阶段 hook 建立离线行为测试：旧 `master.tasks` 也能识别完成阶段；冲突不能静默推进；现有顶层任务不退化。
2. 实现共享任务读取与验证，保留现有 ID 和原始文件，统一文档使用 `tasks`/`dependencies`，兼容旧结构。
3. 编写共享 RCT profile；两套 survey/ideate/experiment/plan/review/setup 及必要 agent 入口引用同一规则，正式 SR 不继续执行精选阅读模板。
4. 修正 R 示例效应尺度、无效参考线、偏倚检验和 tau² 解读；核对 metafor 官方文档。没有 R 环境时如实标注不能进行真实 R 运行验证。
5. 增加双插件规则静态检查，加入现有 `npm run check`，同步技能清单。静态检查不代表 LLM 实际执行得到验证。
6. 运行离线测试和原有检查，检查差异是否超出本轮范围；记录后续 SR-02 起尚未实现的功能。

## 边界

不变更版本号、不提交、不推送、不迁移用户研究目录、不安装依赖、不调用真实研究数据源或远程实验。新的研究前置条件由命令规则检查；本轮不宣称已实现完整的可执行审批系统。
